# Rastreador — página del mapa

Página que muestra en un mapa dónde está mi celular (proyecto antirrobo).
Lee la ubicación desde Firebase. Para usarla: abrir, tocar ⚙️ Ajustes y pegar
la URL de Firebase y la clave secreta (se guardan solo en tu navegador).

Hecha con HTML, JavaScript y Leaflet (mapas de OpenStreetMap).
